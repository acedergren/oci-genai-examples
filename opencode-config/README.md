# OpenCode Configuration

Configuration files for [OpenCode](https://opencode.ai/), an open-source AI coding assistant.

## Usage

Copy `opencode.json` to your project root or reference this configuration in your OpenCode setup.

## Configuration

The `opencode.json` file configures:

- Model preferences
- Provider settings
- Tool configurations
- Context settings

## Files

| File | Description |
|------|-------------|
| `opencode.json` | Main configuration file |
